# TechQuiz - Fundamentos de Desenvolvimento Web e Git

Quiz interativo desenvolvido na matéria de Desenvolvimento Front-end para Web. O projeto tem como objetivo principal estruturar a base visual e o planejamento de um jogo de perguntas e respostas sobre tecnologia.

## 🎯 Tema Escolhido
**Tecnologia e Programação**: Conceitos fundamentais de HTML5, CSS3, JavaScript e controle de versão com Git.

## 🚀 Instruções de Uso
1. Clone este repositório em sua máquina local utilizando o Git.
2. Certifique-se de que os arquivos `index.html`, `style.css` e `perguntas.json` encontram-se na mesma pasta raiz do projeto.
3. Abra o arquivo `index.html` diretamente em seu navegador de preferência ou utilize uma ferramenta de desenvolvimento como o **Live Server** (no Visual Studio Code).
4. Navegue pela página inicial de apresentação e explore a estrutura base da tela de jogo.

## 🛠️ Tecnologias Utilizadas
* HTML5 Semântico
* CSS3 (Flexbox, variáveis customizadas, acessibilidade e design responsivo)
* JSON (Estrutura de dados para as questões)
* Git e GitHub (Controle de versão e hospedagem)
